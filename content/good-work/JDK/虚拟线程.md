## 1. 核心概念  
  
### 1.1 虚拟线程架构  
  
```mermaid  
graph TD  
    OS[操作系统线程] --> VT1[虚拟线程1]  
    OS --> VT2[虚拟线程2]  
    OS --> VT3[...]    VT1 -->|挂载| CT[载体线程池]  
    VT2 -->|挂载| CT  
```  
  
### 1.2 与传统线程对比  
  
| 特性            | 平台线程                  | 虚拟线程                  |  
|-----------------|--------------------------|--------------------------|  
| 资源占用        | 1MB+ 栈内存              | 初始~200B 可伸缩内存       |  
| 创建数量        | 数千级别                 | 数百万级别                |  
| 调度方式        | OS 线程调度              | JVM 协作式调度            |  
| 上下文切换      | 昂贵(OS级别)             | 轻量(JVM级别)             |  
| 阻塞操作影响    | 线程被占用               | 线程可立即重用            |  
  
## 2. 基础API  
  
### 2.1 创建虚拟线程  
  
**方式1：直接创建**  
```java  
Thread vThread = Thread.ofVirtual()  
    .name("worker-", 0)    .start(() -> {        // 任务逻辑  
    });  
```  
  
**方式2：使用ExecutorService**  
```java  
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {  
    executor.submit(() -> {        // 任务逻辑  
    });}  
```  
  
### 2.2 结构化并发  
  
```java  
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {  
    Future<String> user = scope.fork(() -> fetchUser());    Future<Integer> order = scope.fork(() -> fetchOrder());    scope.join();          // 等待所有任务  
    scope.throwIfFailed(); // 检查异常  
        return new Response(user.resultNow(), order.resultNow());  
}  
```  
  
## 3. 性能优化  
  
### 3.1 线程池配置  
  
```java  
// 虚拟线程执行器  
ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor();  
  
// 定制载体线程池  
System.setProperty("jdk.virtualThreadScheduler.parallelism", "32");  
System.setProperty("jdk.virtualThreadScheduler.maxPoolSize", "256");  
```  
  
### 3.2 阻塞操作优化  
  
**IO密集型任务**：  
```java  
void handleRequest(Socket socket) {  
    try (socket) {        String request = new String(            socket.getInputStream().readAllBytes());        String response = processRequest(request);        socket.getOutputStream()            .write(response.getBytes());    }}  
// 每个请求自动分配虚拟线程  
```  
  
## 4. 生产实践  
  
### 4.1 适用场景  
  
1. **高并发IO**：  
   - HTTP服务器  
   - 数据库访问  
   - 微服务调用  
  
2. **异步编程**：  
   - 替代CompletableFuture  
   - 简化反应式代码  
  
3. **批处理任务**：  
   - 并行文件处理  
   - 数据转换流水线  
  
### 4.2 反模式  
  
1. **CPU密集型计算**：  
   ```java  
   // 错误用法 - 不会提升计算性能  
   virtualThread.execute(() -> {  
       computeIntensiveTask();   });  
   ```  
2. **同步器滥用**：  
   ```java  
   // 避免在虚拟线程中使用  
   synchronized(lockObj) {  
       // 长时间持有锁  
   }  
   ```

## 6. 高级特性  
  
### 6.1 线程局部变量  
  
```java  
ThreadLocal<String> user = new ThreadLocal<>();  
try (var scope = new StructuredTaskScope()) {  
    scope.fork(() -> {        user.set("Alice");        processUser();    });    scope.join();}  
// 自动清理ThreadLocal  
```  
  
### 6.2 线程切换控制  
  
```java  
Thread.Builder builder = Thread.ofVirtual()  
    .allowSetThreadLocals(false)    .inheritInheritableThreadLocals(false);  
```
